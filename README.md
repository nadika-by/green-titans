## ⚙️ Цифровой обменник: Отходы как Капитал

**Green Titans** — это децентрализованный протокол, который превращает физические отходы в цифровые активы. Мы создаем систему, где мусор становится финансовым ресурсом для каждого участника.

### Механика взаимодействия:
1.  **ЛЮДИ (Поставщики):** Сдают отсортированные отходы и через мобильное приложение получают мгновенное вознаграждение в токенах, создавая свой личный капитал.
2.  **БИЗНЕС:** Получает чистое сырье для своего производства, а также становится участником системы сдачи промышленных отходов в обмен на токены, оптимизируя свои расходы.
3.  **БЛОКЧЕЙН (Solana):** Гарантирует прозрачность обмена и мгновенную фиксацию каждой транзакции в публичном реестре.
4.  **ГОСУДАРСТВО:** Обеспечивает легитимность системы и контроль исполнения экологических норм в рамках ГЧП.
